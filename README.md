## 🚀 Publicación rápida en GitHub Pages

1. **Crear repositorio en GitHub:**
   Crea un nuevo repositorio en GitHub (por ejemplo: `jornada-finados-halloween`).

2. **Subir los archivos:**
   Sube el contenido de esta carpeta (`index.html`, `style.css`, `script.js` y la carpeta `assets/`).

   ```bash
   git init
   git add .
   git commit -m "Web interactiva Jornada Finados y Halloween IES Santa Lucía"
   git branch -M main
   git remote add origin https://github.com/TU-USUARIO/jornada-finados-halloween.git
   git push -u origin main
   ```

3. **Activar GitHub Pages:**
   - En tu repositorio de GitHub, ve a **Settings** > **Pages**.
   - En **Build and deployment** / **Source**, selecciona `Deploy from a branch`.
   - Elige la rama `main` y la carpeta `/ (root)`.
   - Pulsa **Save**. En 1 o 2 minutos tendrás tu enlace web público activo.
